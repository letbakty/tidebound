# Этап 15 — Экраны: меню, драфт, итоги, журнал, настройки, пауза

**Модель:** Sonnet 5 достаточно (много однотипной вёрстки по спеке); Fable 5 — если хочется лучшей полировки за один проход.
**Зависит от:** 12–14; sim 10–11. **Читать:** docs/01 §3; docs/00 §11–12 (переходы!).
**Ресерч:** [research/22-screens-routing-i18n.md](../research/22-screens-routing-i18n.md) — роутер по видимости (не `change_scene`), автопауза со счётчиком, локализация на лету, настройки и масштаб UI, `HintCard`. Дополнительно: [research/21](../research/21-hud-panels-tween.md).

## Задача
1. **Роутер экранов** `ui/screens/screen_router.gd`: состояния Boot→MainMenu→Game→(Summary→Journal)→MainMenu по docs/00 §12. ⚠️ **Роутинг переключением видимости, а не `change_scene_to_*`** ([research/22](../research/22-screens-routing-i18n.md) §1): пересоздание игровой сцены убьёт состояние забега и все кэши виджетов. Автопауза — **счётчиком** (сколько сущностей просят паузу), а не булевым флагом, иначе драфт поверх итога цикла снимет паузу раньше времени ([research/22](../research/22-screens-routing-i18n.md) §2).
2. **MainMenu** `ui/screens/main_menu.tscn`: логотип-заглушка, [Продолжить] (видна при Game.has_save(), с подтверждением затирания при [Новый забег]), [Новый забег] (поле сида — опционально, пусто = случайный), [Журнал], [Настройки], [Выход]. Фон — живой: world.tscn с автопилотной камерой? НЕТ — слишком дорого; фон = статичная картинка-заглушка (TODO арт).
3. **DraftPanel**: полноэкранная, автопауза уже сделана sim'ом: 3–4 card_view по draft_ready, тап — подсветка + кнопка «Выбрать» (двухшаговое подтверждение против мисс-тапов) → cmd_pick_card.
4. **CycleSummary** (cycle_ended): три колонки чипов (добыто/произведено/потеряно из report), список событий строками, прогноз следующего цикла (иконки), кнопка «Дальше» (снимает автопаузу). Держи компактно: один экран без скролла на телефоне.
5. **RunSummary** (run_ended): исход (SHIP/WIPE/EARLY — заголовок и тон), разбивка очков по категориям с построчным «подъездом» чисел (Tween), выжившие и погибшие (эпитафии), сид забега (тап — копировать), «В Журнал».
6. **Journal** `ui/screens/journal.tscn`: вкладки (TabContainer): Разблокировки — сетка 12 карточек (куплено/доступно/дорого; тап — подтверждение покупки → Meta.buy_unlock), баланс очков крупно; История — список забегов + общая статистика и счётчик реликвий (Meta, docs/00 §11.3); Павшие — список эпитафий. Новые разблокировки после RunSummary — подсвечены.
7. **Settings**: громкости (master/music/sfx — шины этапа 17, пока заглушки), масштаб UI (слайдер 75–150% → Window.content_scale_factor), дефолтный зум мира, язык (ru/en — TranslationServer.set_locale + сохранение в Settings-автолоад → user://settings.json), переключатель подсказок HintCard, сброс профиля (двойное подтверждение).
8. **PausePanel** (Esc в Game): продолжить/настройки/покинуть забег (→ подтверждение → cmd_leave_early если ≥8 цикл, иначе `Game.cmd_surrender()` с двойным подтверждением)/гл. меню (автосейв). Внизу — сид забега (LabelNum, тап копирует в буфер: DisplayServer.clipboard_set).
9. **HintCard** (Learning Helper, docs/01 §3): очередь карточек-уроков по первым событиям типов (словарь hint_id → tr-ключи; триггеры: первый мокрый плавник, первое объявление шторма, первый Приход, первая порча, первое затопление склада). Правый верх, не перекрывает тосты; «понятно» закрывает; показанные — словарь `shown_hints` в Game, сериализуется ui-секцией save_run.json (контракт этапа 11); межзабежные хинты — в Meta.

## Приёмка
- [ ] Полная петля: меню → забег → 12 циклов (можно дебаг-промоткой) → итог → журнал → покупка разблокировки → новый забег с её эффектом.
- [ ] Смена языка на лету меняет все строки (нет захардкоженных).
- [ ] Масштаб UI работает на 1280×720 и 1920×1080 без поломки лейаута.
- [ ] Continue восстанавливает игру из сейва в то же состояние (визуально и по данным).
