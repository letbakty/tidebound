## Задача
1. **Роутер экранов** `ui/screens/screen_router.gd`: состояния Boot→MainMenu→Game→(Summary→Journal)→MainMenu по docs/00 §12. ⚠️ **Роутинг переключением видимости, а не `change_scene_to_*`** ([research/22](../research/22-screens-routing-i18n.md) §1): пересоздание игровой сцены убьёт состояние забега и все кэши виджетов. Автопауза — **счётчиком** (сколько сущностей просят паузу), а не булевым флагом, иначе драфт поверх итога цикла снимет паузу раньше времени ([research/22](../research/22-screens-routing-i18n.md) §2).
1a. **Boot** (§3.1) — логотип, полоса загрузки, версия сборки в углу. Живёт доли секунды, но без него первый кадр чёрный и игрок думает, что игра зависла. Профиль повреждён → сразу `ErrorDialog`.
1b. **FirstLaunch** (§3.2) — показывается один раз, когда профиля нет. Два шага: язык (названиями самих языков, дефолт по системной локали) и предложение настроить доступность или пропустить. Отраслевой стандарт: доступность предлагается на первом запуске, а не прячется в третьей вкладке. ⚠️ Настройки доступности **никогда** не отключают достижения.
1c. **ErrorDialog** (§4.5) — что случилось человеческим языком, что игра сделала («Сейв повреждён и не загружен. Прогресс Журнала цел»), что можно сделать. Кнопки «В главное меню» и «Скопировать детали» (техинформация в буфер для баг-репорта).
2. **MainMenu** `ui/screens/main_menu.tscn`: логотип-заглушка, [Продолжить] (видна при Game.has_save(), с подтверждением затирания при [Новый забег]), [Новый забег] (поле сида — опционально, пусто = случайный), [Журнал], [Настройки], [Выход]. Фон — живой: world.tscn с автопилотной камерой? НЕТ — слишком дорого; фон = статичная картинка-заглушка (TODO арт).
3. **DraftPanel**: полноэкранная, автопауза уже сделана sim'ом: 3–4 card_view по draft_ready, тап — подсветка + кнопка «Выбрать» (двухшаговое подтверждение против мисс-тапов) → cmd_pick_card.
4. **CycleSummary** (cycle_ended): три колонки чипов (добыто/произведено/потеряно из report), список событий строками, прогноз следующего цикла (иконки), кнопка «Дальше» (снимает автопаузу). Держи компактно: один экран без скролла на телефоне.
5. **RunSummary** (run_ended): исход (SHIP/WIPE/EARLY — заголовок и тон), разбивка очков по категориям с построчным «подъездом» чисел (Tween), выжившие и погибшие (эпитафии), сид забега (тап — копировать), «В Журнал». ⚠️ **При проигрыше экран обязан показать, что игрок ПОЛУЧИЛ** — сколько очков ушло в Журнал и что теперь по карману. Смягчение проигрыша метапрогрессией — то, на чём держится весь жанр; экран, показывающий только потери, гонит игрока из игры.
6. **Journal** `ui/screens/journal.tscn`: вкладки (TabContainer): Разблокировки — сетка 12 карточек (куплено/доступно/дорого; тап — подтверждение покупки → Meta.buy_unlock), баланс очков крупно; История — список забегов + общая статистика и счётчик реликвий (Meta, docs/00 §11.3); Павшие — список эпитафий. Новые разблокировки после RunSummary — подсвечены рамкой до первого просмотра. ⚠️ **Пустые состояния обязательны:** до первого забега все три вкладки пусты — это должно выглядеть осмысленно («Здесь появятся ваши забеги»), а не сломанно.
7. **Settings** — **пять вкладок по [docs/03](../docs/03-screens-spec.md) §3.6**, применение сразу без кнопки «Сохранить», каждая настройка с одной строкой пояснения:
   - **Игра:** язык (`TranslationServer.set_locale` + `user://settings.json`) · подсказки HintCard · **какие события ставят автопаузу (три флажка: драфт, итог цикла, первый кризей)** · скорость по умолчанию · внизу блок «Данные»: путь к сейвам, сброс профиля (двойное подтверждение), версия сборки.
   - **Экран:** масштаб UI 75–150% (`Window.content_scale_factor`) · зум мира по умолчанию · полноэкранный режим · вертикальная синхронизация · целочисленное масштабирование с пояснением «чётче пиксели, но чёрные поля».
   - **Звук:** общая / музыка / эффекты / интерфейс / окружение · вибрация (только телефон).
   - **Управление** *(каркас в MVP, наполнение в этапе 16):* схема · список клавиш с подсветкой конфликтов · чувствительность камеры · сброс к умолчаниям.
   - **Доступность:** размер шрифта **отдельно** от масштаба UI · три пресета для дальтоников · снижение анимаций · повышенный контраст панелей · время автозакрытия тостов вплоть до «не закрывать» · озвучка меню экранным диктором (`AccessKit` есть с Godot 4.5 — включить и проверить, это почти бесплатно).
8. **PausePanel** (Esc в Game): продолжить/настройки/покинуть забег (→ подтверждение → cmd_leave_early если ≥8 цикл, иначе `Game.cmd_surrender()` с двойным подтверждением)/гл. меню (автосейв). Внизу — сид забега (LabelNum, тап копирует в буфер: DisplayServer.clipboard_set).
8a. ⚠️ **Счётчик глубины паузы обязателен** (review/01, SIM-04 и SIM-10). Сейчас `cycle_ended` и `draft_ready` приходят в одном тике и перезаписывают одну переменную — скорость молча падает с ×3 на ×1 каждый цикл, одиннадцать раз за забег. Плюс `speed` проверяется один раз на входе в `_physics_process`, поэтому после конца цикла проходит до 11 лишних тиков: отчёт цикла может разойтись с тем, что на экране. Пауза — счётчик, а не флаг; снятие — только когда счётчик обнулился.
8b. **HintCard на объявление сизигии 12-го цикла** (review/02, SPEC-01): событие `crisis_announced(SPRING_TIDE, 12)` уже эмитится, и docs §11.2 прямо обещает подсказку «ценное поднять на ≥+3». Не пропусти этот триггер — без него финальное испытание останется необъяснённым.
9. **SaveIndicator** (§6) — маленькая метка «сохранено» на границе цикла. Без неё игрок не знает, что прогресс цел, и боится закрывать игру.
10. **Credits** *(релиз, каркас сейчас)* — прокручиваемый список: разработчик, шрифты **с их лицензиями** (OFL и CC0 требуют указания — это юридическая обязанность, а не вежливость), звуки, библиотеки, плейтестеры. Тап — пропуск.
11. **HintCard** (Learning Helper, docs/01 §3): очередь карточек-уроков по первым событиям типов (словарь hint_id → tr-ключи; триггеры: первый мокрый плавник, первое объявление шторма, первый Приход, первая порча, первое затопление склада). Правый верх, не перекрывает тосты; «понятно» закрывает; показанные — словарь `shown_hints` в Game, сериализуется ui-секцией save_run.json (контракт этапа 11); межзабежные хинты — в Meta.

## Приёмка
- [ ] Полная петля: меню → забег → 12 циклов (можно дебаг-промоткой) → итог → журнал → покупка разблокировки → новый забег с её эффектом.
- [ ] Смена языка на лету меняет все строки (нет захардкоженных).
- [ ] Масштаб UI работает на 1280×720 и 1920×1080 без поломки лейаута.
- [ ] Continue восстанавливает игру из сейва в то же состояние (визуально и по данным).
- [ ] Все краевые случаи из [docs/03](../docs/03-screens-spec.md) §8 отработаны явно: битый сейв, выход во время драфта, конец забега при открытой панели, гибель всех на границе цикла, ноль ресурсов, 16 агентов, окно 800×600 и 3840×2160.
- [ ] **Вся навигация проходима только геймпадом** уже здесь, а не на этапе 16: фокус виден, порядок обхода логичен, Esc/B возвращают назад. Добавлять контроллер после мыши — типовая причина отказа в Steam Deck Verified.
