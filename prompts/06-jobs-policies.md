# Этап 06 — Работы, скоринг, политики, маяк

**Модель:** Opus 5 или Fable 5 (поведенческое ядро игры).
**Зависит от:** 05. **Читать:** docs/00 §6.5–6.7, §3.2 (депозиты).
**Результат:** колония самоуправляется: добывает, носит на склады, ест, отдыхает; игрок влияет только политиками, маяком и отзывом.
**Ресерч:** [research/16-jobs-utility-ai-reservation.md](../research/16-jobs-utility-ai-reservation.md) — утилитарный скоринг, резервирование, пул задач по событиям, два фильтра вместо двух скорингов, маяк. Дополнительно: [research/11](../research/11-sim-core-determinism.md) §1.1 (**`sort_custom` не стабилен**), [research/25](../research/25-cross-engine-patterns.md).

## Задача
1. `sim/policy_set.gd` — `class_name PolicySet`: 6 значений 0..3 (enum SimTypes.Policy), дефолты из docs/00 §6.6, `to_dict/from_dict`. Команда `Game.cmd_set_policy(policy, value)` + событие policy_changed.
2. `sim/job_system.gd` — `class_name JobSystem`. Модель: **задачи порождает мир, а не агент** («реклама» из The Sims), конфликты решает резервирование (модель RimWorld, ~20 строк) — [research/16](../research/16-jobs-utility-ai-reservation.md) §1–3. Пул задач перестраивается **по событиям**, а не каждый тик; выбор из пула — каждый тик. Генерация задач из состояния мира:
   - GATHER: по каждому непустому депозиту в досягаемости (не затоплен, mark ≥ будущего уровня при текущей фазе-безопасности НЕ проверяем — за риск отвечает игрок политиками).
   - HAUL: предмет на земле → ближайший склад со свободным слотом; со склада к станции — этап 08 (заглушка-интерфейс `request_haul(from, to, item, n)` для будущих этапов).
   - EAT/REST — как потребностные задачи (уже в 05, перевести на общий скоринг).
   - BUILD/REPAIR/STATION — интерфейсы-заглушки (этапы 07–08).
   - ⚠️ **`Array.sort_custom` в Godot не стабилен** — при равных score агенты пойдут в разные места между прогонами, и детерминизм рухнет. Решение ([research/11](../research/11-sim-core-determinism.md) §1.1): считать score во float, но **кэшировать в задаче как `score_q: int` (квантование `int(round(score*100))`)** и сортировать по нему с тотальным компаратором — последним ключом всегда `id`.
   - Скоринг дословно по docs/00 §6.5: `score = policy_weight × base × urgency ÷ (1 + 0.1 × dist)`; policy_weight=0 → класс запрещён. Городить резервирование: задача назначена — другой агент её не берёт; отмена при недостижимости.
3. Ограничение Жадности: цель дальше N тайлов от ближайшей лестницы (N по §6.6) — отфильтрована. Жадность 3 — без лимита.
4. Авто-возврат Осторожности: на фазе SIGNAL за [0/20/40/60] с до конца — авто-recall(false) только для агентов ниже отметки 0. Паника (mood<30): персональный сдвиг +20 с раньше.
5. Маяк: поле в SimWorld `beacon_cell`; `Game.cmd_set_beacon(cell)`; бонус скоринга ×1.3 задачам в радиусе 12 тайлов; событие beacon_moved.
6. GATHER-исполнение: агент у депозита, 1 ед./2 с (× work_mult), в котомку; котомка полна или депозит пуст → само-HAUL к ближайшему складу. Реликвия: ТОЛЬКО на депозитах с отметок −7..−8, шанс Balance.RELIC_CHANCE=0.15 на добычу (× relic_chance_mult черты Зоркий), максимум 1 реликвия на депозит (флаг); событие + mood +10 всем.
7. **Автовыдача Снаряжения** (docs/00 §7): при появлении `gear` на складе — выдать агенту с наибольшей «глубинной полезностью» (сумма добытых единиц с отметок ≤ −5 за последний цикл; при равенстве — старший id для детерминизма): has_gear=true, занимает слот котомки. При смерти агента снаряжение теряется. Тест: агент с gear переживает 10-секундное погружение.
8. **Отчёт цикла:** агрегируй добытое за цикл (item_id → count) и передай в report события cycle_ended (колонка «добыто» для CycleSummary этапа 15).

## Приёмка (tests/test_jobs.gd)
- [ ] За полный цикл при дефолтных политиках 6 агентов приносят на склад ≥8 утиля и ≥4 catch (подобрать карту-минимум в тесте).
- [ ] Жадность 0: никто не берёт задачи дальше 4 тайлов от лестниц; Жадность 3: берут дальние.
- [ ] Осторожность 3: к началу HIGH никто не ниже −1; Осторожность 0 + Жадность 3: хотя бы один агент реально рискует (проверь, что счётчик погружения у кого-то тикал).
- [ ] Заготовка=0 — никто не добывает; Отдых=3 — на HIGH все едят/отдыхают.
- [ ] Маяк смещает выбор: при двух равных депозитах берут тот, что у маяка.
- [ ] Детерминизм-прогон 20 000 тиков зелёный.
