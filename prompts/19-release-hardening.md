## Задача
1. **Автопилотный стресс:** headless-прогон 20 забегов разными сидами (скрипт tests/soak.gd; готовая схема с CSV — [research/24](../research/24-testing-headless-hardening.md) §6): ни одного краша/ошибки; собери статистику (очки, выжившие, причины смертей) в CSV — это заготовка баланс-данных.
2. **Санитария детерминизма:** повтори хеш-тест после КАЖДОЙ системы. Grep-аудит — **перенеси готовый `research/code/audit_sim.sh` в `tools/`** (проверяет все шесть источников недетерминизма из [research/11](../research/11-sim-core-determinism.md) §1, не только `randf`): глобальный RNG, `Time.*`, нестабильные сортировки, float-накопители, итерация по словарям, нодовые API в `sim/`.
3. **Санитария сигналов:** скрипт-проверка: каждый сигнал Events кем-то эмитится и кем-то слушается (мёртвые — в отчёт); сигнатуры обработчиков совпадают (в debug-сборке прогон с проверкой).
4. **Память:** 3 забега подряд без выхода — снапшоты памяти, утечки (незакрытые View при run_ended, копящиеся тосты, орфаны нод — `print_orphan_nodes`).
5. **Краевые случаи:** загрузка битого сейва (обрезанный JSON) — мягкий отказ; сейв в момент смерти агента; выход во время драфта; пауза во время подъёма воды; окно 800×600 и 3840×2160.
6. **Локализация:** прогон обоих языков — нет ключей «сырых» (`KEY_NAME` на экране), нет вылезающего за панели текста (RU длиннее EN на ~20%).
7. **Релизная часть** по [research/26](../research/26-build-size-and-optimization.md) §2–3, §7: настройки экспорта уровня 0 (ничего не стоят), strip и упаковка дистрибутива, замер итогового размера билда. ⚠️ UPX не применять (§4), список «что НЕ делать» — §8.
8. TODO-инвентаризация: собери все `TODO` по проекту в docs/backlog.md с приоритетами.
