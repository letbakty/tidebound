# Этап 13 — HUD: шкала прилива, TopBar, кнопка отзыва, банеры

**Модель:** Fable 5 (визуально ответственный этап) или Sonnet 5.
**Зависит от:** 12 + sim-этапы до 06 (для данных). **Читать:** docs/01 §2 (весь, там ASCII-макет); docs/00 §13.
**Ресерч:** [research/21-hud-panels-tween.md](../research/21-hud-panels-tween.md) — кэши виджетов вместо чтения sim, `TideGauge` в `_draw`, Tween 4.7, тосты и мёртвая зона, банер и автопауза. Дополнительно: [research/06](../research/06-pixel-art-pitfalls.md) §9 (**в 4.7 `_draw` больше не добавляет feather — ширину линий задавать явно**).

## Задача
1. `ui/hud/tide_gauge.tscn/gd` — левый край, ширина ~56px UI. ⚠️ **В 4.7 `CanvasItem` больше не добавляет antialiasing feather при рисовании линий (GH-105122)** — ширину всех линий в `_draw` задавать явно, иначе шкала будет выглядеть иначе, чем ожидалось ([research/06](../research/06-pixel-art-pitfalls.md) §9). Разбор единственного сложного `_draw` в проекте — [research/21](../research/21-hud-panels-tween.md) §2.
   - Отрисовка `_draw()`: шкала отметок +6..−12, залитая зона текущей воды (WATER_COLD), стрелка-поплавок уровня, риски ярусов с подписями каждые 2, точки построек по отметкам (цвет: норм/damaged/flooded), линия плато LOW текущего цикла.
   - Прогноз: 3 мини-иконки будущих циклов (обычный/сизигия/шторм — с момента announce) + таймер текущей фазы (mm:ss) и имя фазы.
   - Подписки: water_level_changed, phase_changed, crisis_announced, building_*; данные о постройках — из событий (кэш в ноде), НЕ из sim.
   - Тап по шкале — тултип-легенда (что значат метки).
2. `ui/hud/top_bar.tscn/gd` — строка сверху: кнопка паузы + скорости ×1/×2/×3 (подсветка активной; Space и 1/2/3 уже в input map — обработку сюда), «Цикл N/12», 4 ResourceChip (rations, freshwater, driftwood-сухой, part) с трендом (сравнение с началом прошлого цикла — считай в ноде по resources_changed), ряд AgentChip: тап — плавный центр камеры на агенте (сигнал в CameraRig, БЕЗ «похищения» камеры при событиях), второй тап — заглушка карточки (панель на этапе 14).
3. `ui/hud/recall_button.tscn/gd` — правый низ, 64×64+ : иконка колокола; на SIGNAL — пульсация (Tween scale 1.0↔1.08); нажатие → Game.cmd_recall(false); повторное в 2 с → cmd_recall(true) с визуальным отличием; счётчик «внизу осталось: N» рядом с кнопкой, когда кто-то ниже 0 в SIGNAL/HIGH.
4. ⚠️ **Единая очередь уведомлений с приоритетами** (тост / банер / подсказка этапа 15) — заводить сразу здесь, иначе на 15-м они начнут накладываться друг на друга ([research/25](../research/25-cross-engine-patterns.md) §4). `ui/hud/toast_stack.tscn/gd` — правый край над кнопкой отзыва (мёртвая зона кнопки — не перекрывать!): группировка по типу за 10 с (×3), важность цветом, тап — центр камеры к месту события (если в событии есть cell), свайп — скрыть.
5. `ui/hud/banner_view` (из компонентов) — crisis_announced/started: полоса сверху с автопаузой при первом появлении типа за забег. Запоминание: словарь `shown_banners` живёт в Game (не в sim) и сериализуется ui-секцией save_run.json (контракт этапа 11).
6. **Игровые оверлеи мира** (docs/01 §2, НЕ путать с дебаг-оверлеями этапа 03 — те за is_debug_build): Node2D в мире + тумблеры F2/F3/F4: «отметки ярусов» (подписи у края), «зоны затопления следующего цикла» (полупрозрачная заливка клеток ниже плато следующего цикла с учётом сизигии — данные из crisis_announced и Balance), «кто чем занят» (иконка класса задачи над каждым агентом). Один активный оверлей за раз.
7. Сборка: `ui/hud/hud.tscn` на HUDLayer; safe area: MarginContainer с отступами из DisplayServer.get_display_safe_area() с фолбэком ≥12px (docs/01 §5).

## Приёмка
- [ ] Играется полный цикл только с HUD: видно фазу/уровень/прогноз, отзыв работает, скорость переключается, тосты группируются.
- [ ] Шкала корректно показывает сизигию (+2) и объявленный шторм.
- [ ] Все элементы — через тему и tr(); на окне 1280×720 и 1920×1080 HUD не наезжает на мир.
- [ ] Тап по AgentChip центрирует камеру плавно; никакого автозума от событий.
- [ ] F3 показывает зону следующего затопления; в цикл перед сизигией зона выше обычной.

## Не делать
Панели (14–15), финальные иконки (18), звук (17).
