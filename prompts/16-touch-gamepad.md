# Этап 16 — Тач-платформы и геймпад/Deck

**Модель:** Sonnet 5 достаточно; Fable 5 — если будут сложности с жестами.
**Зависит от:** 13–15. **Читать:** docs/00 §13 (таблица управления); docs/01 §5.
**Ресерч:** [research/20-input-gestures-gamepad.md](../research/20-input-gestures-gamepad.md) — геймпад и фокус, safe area и DPI, проверка «цель ≥48dp», `export_presets.cfg` и сборка из CLI. Дополнительно: [research/10](../research/10-project-setup-viewport-scaling.md) §1 (дробный масштаб — проверить на 1366×768), [research/26](../research/26-build-size-and-optimization.md) §2 (настройки экспорта, которые ничего не стоят).

## Задача
1. **Аудит жестов** по таблице docs/00 §13: пинч-зум ступенями (плавный визуальный переход, «приземление» на целое — docs/01 §1.1), двойной тап по пустому — цикл скоростей, edge-swipe — политики, long-press-прогресс виден у пальца. Всё должно работать в эмуляции тача редактора.
2. **Геймпад/Deck:** курсор-режим: правый стик двигает виртуальный курсор (видимый), A — тап, Y — радиал у курсора, B — отзыв, LB — политики, X — маяк, D-pad — скорость, Start — пауза. Фокус-навигация в панелях — стиком/D-pad (Godot focus neighbors — проверь все панели). Иконки подсказок кнопок в HUD при активном геймпаде (`Input.get_connected_joypads`, автопереключение по последнему вводу).
3. **Мобильный прогон** (если есть устройство/эмулятор; иначе — код-ревизия по чеклисту): все цели ≥48dp при UI scale 100% на 6.1" (используй Window.content_scale_factor из DPI — формула в docs/01 §1.1); safe area учтена; производительность: profiler, узкие места — в отчёт.
4. `export_presets.cfg`: пресеты Windows/Linux/macOS (Steam) + Android (debug) + iOS (заглушка, полноценно — при мобильном релизе). Iконка-заглушка.
5. Deck-чеклист: раскладка по умолчанию, читаемость UI 125%, 60 fps на среднем зуме (профилируй в headless нельзя — отметь TODO ручной проверки).

## Приёмка
- [ ] Вся игра проходима только геймпадом (без мыши): меню→забег→панели→итог.
- [ ] Вся игра проходима только тачем (эмуляция): каждый пункт таблицы §13 отработан.
- [ ] Android-сборка собирается (если SDK доступен; иначе пресет готов и отмечен TODO).
