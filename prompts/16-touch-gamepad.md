В ките все цели уже подняты до 48 dp, минимальный кегль 11 px при требовании Steam Deck 9 px — сверяйся с этими значениями.

## Задача
1. **Аудит жестов** по таблице docs/00 §13: пинч-зум ступенями (плавный визуальный переход, «приземление» на целое — docs/01 §1.1), двойной тап по пустому — цикл скоростей, edge-swipe — политики, long-press-прогресс виден у пальца. Всё должно работать в эмуляции тача редактора.
2. **Геймпад/Deck:** курсор-режим: правый стик двигает виртуальный курсор (видимый), A — тап, Y — радиал у курсора, B — отзыв, LB — политики, X — маяк, D-pad — скорость, Start — пауза. Фокус-навигация в панелях — стиком/D-pad (Godot focus neighbors — проверь все панели). Иконки подсказок кнопок в HUD при активном геймпаде (`Input.get_connected_joypads`, автопереключение по последнему вводу).
3. **Мобильный прогон** (если есть устройство/эмулятор; иначе — код-ревизия по чеклисту): все цели ≥48dp при UI scale 100% на 6.1" (используй Window.content_scale_factor из DPI — формула в docs/01 §1.1); safe area учтена; производительность: profiler, узкие места — в отчёт.
4. `export_presets.cfg`: пресеты Windows/Linux/macOS (Steam) + Android (debug) + iOS (заглушка, полноценно — при мобильном релизе). Iконка-заглушка.
5. **Steam Deck Verified — чеклист по реальным причинам отказов 2026:**
   - ⚠️ **Ни один шрифт не мельче 9 пикселей на экране 1280×800** — жёсткое требование верификации. Проверь каждый мелкий текст: подписи чипов, цены в Журнале, эпитафии, версия сборки.
   - Игра поддерживает 1280×800 и 1280×720 как есть, с хорошими дефолтами (UI 125%, зум мира ×2).
   - **Вся навигация — геймпадом, без единого обращения к клавиатуре.** Клавиатурно-первые меню — самая частая причина отказа у инди.
   - Экранная клавиатура вызывается для любого поля ввода (поле сида, слово подтверждения при сбросе профиля).
   - Никакого лаунчера перед игрой.
   - 60 fps на среднем зуме (в headless не измерить — отметь TODO ручной проверки).
6. **Доступность** (вкладка настроек из этапа 15, наполнение здесь): ремап всех действий с подсветкой конфликтов, три пресета для дальтоников поверх нашей палитры, снижение анимаций, размер шрифта отдельно от масштаба UI, проверка озвучки меню через `AccessKit`. ⚠️ Ни одна настройка доступности не отключает достижения и не помечает забег.
