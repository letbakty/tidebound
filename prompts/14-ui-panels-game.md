# Этап 14 — Игровые панели: стройка, политики, агент, склад, маяк

**Модель:** Fable 5 или Sonnet 5 (вёрстка по спеке; радиал-интеграция — средняя сложность).
**Зависит от:** 12, 13; sim-этапы 06–08. **Читать:** docs/01 §3 (таблица панелей), §5; docs/00 §6.6–6.7, §8.
**Ресерч:** [research/21-hud-panels-tween.md](../research/21-hud-panels-tween.md) §6–8 — `PanelHost`, bottom sheet с перетаскиванием, `AgentCard` через pull. Дополнительно: [research/17](../research/17-buildings-production.md) §3 (призрак размещения), [research/20](../research/20-input-gestures-gamepad.md).

**Макет:** [../design/tidebound-ui-kit.dc.html](../design/tidebound-ui-kit.dc.html) — артборды **V** (панели поверх живой игры: политики, агент, склад, станция, постройка), **H** (радиал и призрак постройки), **O** (классы окон: чем панель отличается от модального окна — панель НЕ затемняет мир), **W** (карточка агента на трёх экранах).

## Задача
1. **PanelHost** `ui/panels/panel_host.gd` (на PanelLayer): реестр панелей, «одновременно открыта максимум одна» (открытие новой закрывает старую), Esc/свайп-вниз/крестик закрывают, сигналы ui_panel_opened/closed в Events. Панели НЕмодальные: мир виден и тикает (кроме автопаузных).
2. **BuildRadial**: по long-press на месте в мире (сигнал InputService.world_long_pressed) / клавише B у курсора — radial_menu с доступными постройками (список: BuildingDef без unlock_id или разблокированные; >6 — слот «ещё» открывает вторую страницу радиала). Выбор → build_ghost (из этапа 07) к этой точке → тап/клик = cmd_place_building, тап мимо = отмена. Призрак: линии до ближайших складов с материалами (паттерн Against the Storm) — прямые Line2D в мире, данные из событий/кэша HUD.
3. **PolicyPanel**: шторка справа (edge_swipe_right / P): 6 policy_slider с tr-подписями и текущими значениями (policy_changed), изменение → cmd_set_policy немедленно (без «применить»). Внизу — подпись-подсказка выбранного значения («Осторожность 2: возврат за 40 с» — словарь описаний в панели).
4. **AgentCard**: bottom sheet (ПК — нижняя панель): setup по id из кэша событий agent_updated (через `Game.query_agent(id) -> Dictionary` — единственный разрешённый «pull», уже объявлен в docs/02 §3.3: Game синхронно собирает словарь-срез из sim, sim об UI не знает).
⚠️ **Вызывать не чаще раза в секунду и только пока карточка открыта** (review/04, PERF-01): `AgentView` в текущем коде дёргает полный срез каждый кадр — это 60 словарей в секунду на агента без всякой нужды. Состав: имя, строка биографии (bio_key), черты (тап — тултип с описанием), 3 полосы потребностей (цвет по порогам), состояние строкой, котомка 4 слота (+ иконка снаряжения при has_gear), кнопка «к агенту» (центр камеры). Обновление раз в секунду пока открыта.
5. **StationPanel** — **окно, которого не было в ТЗ; см. [docs/03-screens-spec.md](../docs/03-screens-spec.md) §5.4.** Тап по горну, испарителю, солильне, канатной, сушилам, лебёдке. Без него игрок не может понять, **почему цепочка встала** — главный источник фрустрации в жанре. Состав: рецепт наглядно (входы → выход) · буфер станции (что принесено, чего не хватает) · прогресс работы · **причина простоя явным текстом** (затоплена / повреждена / нет материалов / нет топлива / никто не идёт при Заготовке 0 / некуда класть готовое) · кнопки «Починить» и «Снести» с подтверждением.
6. **BuildingPanel** (§5.5) — общая панель для построек без своей логики (лестница, помост, койка, очаг, фонарь, шлюз, дождесборник): что это, состояние, расход топлива с остатком у очага и фонаря, «Починить» / «Снести».
7. **DepositTooltip** (§6) — наведение или долгое нажатие на депозит: сколько осталось, восполняется ли, есть ли шанс реликвии.
8. **StoragePanel**: тап по складу в мире (world_tapped → хит-тест по view) — сетка стаков: иконка, число, капля (wet), пирог-таймер порчи. Информация без управления.
9. **Маяк**: кнопка на TideGauge (или M): режим установки — следующий тап по миру = cmd_set_beacon; маркер маяка в мире (`game/beacon_view.tscn` — флажок-заглушка с радиусом 12 полупрозрачным кругом при выборе).
10. Тач-полировка: все цели ≥48dp; bottom sheet перетаскивается пальцем (полэкрана ↔ четверть).

## Приёмка
- [ ] Полный цикл играется мышью И тачем (эмуляция) без дебаг-панели: строить, политики, маяк, отзыв.
- [ ] Открытие любой панели закрывает предыдущую; Esc закрывает; мир не замирает.
- [ ] AgentCard живая (потребности движутся), «к агенту» работает.
- [ ] StationPanel называет причину простоя для всех шести случаев (проверить каждый, отключая условия по очереди) — это главная приёмка этапа.
- [ ] Хит-тест различает склад, станцию, прочую постройку и депозит: каждый открывает своё.
- [ ] Радиал: страница «ещё» появляется при >6 построек; недоступные (unlock) не показываются.

## Не делать
Экранные панели (15), звук, атлас-скин.
