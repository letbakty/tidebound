# Этап 05 — Агенты: FSM, движение по графу, потребности, утопление

**Модель:** Opus 5 или Fable 5 (самый сложный sim-этап).
**Зависит от:** 01, 02, 04. **Читать:** docs/00 §6 (весь, кроме 6.5–6.6 — они на этапе 06); docs/02 §3, §4.
**Результат:** 6 агентов живут в мире: ходят, несут, тонут, мёрзнут, едят; видны на экране.
**Ресерч:** [research/15-agents-fsm-views.md](../research/15-agents-fsm-views.md) — FSM без нод, приоритетные прерывания, гистерезис потребностей, утопление, синхронизация View, хит-тест без физики. Дополнительно: [research/11](../research/11-sim-core-determinism.md) §1.3 (**потребности целочисленно — иначе приёмка save→load не пройдёт**).

## Задача — sim
1. `data/defs/trait_def.gd` + `data/traits/*.tres` — 20 черт из docs/00 §6.4. Модель эффектов: `@export modifiers: Dictionary[String, float]` с фикс-ключами (`speed_mult, ladder_speed_mult, bag_slots_add, drown_seconds, min_mark, forge_mult, saltery_mult, hunger_rate_mult, warmth_rate_mult, mood_aura, relic_chance_mult, drop_chance, panic_range, work_mult, carry_mult, rest_need_mult, rest_gain_mult, no_panic, no_rest_cycles, idle_mood_penalty`). Черта = набор пар; неиспользуемые ключи отсутствуют.
2. `sim/sim_agent.gd` — `class_name SimAgent`: id, имя, 2 trait_id, позиция (platform_id + x: float), состояние `SimTypes.AgentState`, котомка `Array[Dictionary]` (стаки, 4 слота + модификаторы), потребности (satiety, warmth, mood: float 0..100; скрытая fatigue), флаги wet/has_gear, счётчик погружения (тики под водой). `modifier(key, default=1.0)` — свёртка по чертам.
3. `sim/agent_system.gd` — `class_name AgentSystem`:
   - Спавн 6 агентов при new_run (имена из const-пула 40, черты — 2 разные, сид).
   - Движение: путь = Array[platform_id] из Terrain.find_path; скорость 2.0 т/с × модификаторы, лестницы 1.2 т/с; позиция обновляется тиком.
   - FSM из docs/00 §6.2. На этом этапе реализуй: IDLE (стоит/бродит по площадке), GOTO, RETURN (к spawn_cell/выше отметки будущей воды), REST (в койке/у очага: fatigue↑), EAT (у склада с едой: rations→+60, catch→+30 и mood−5), PANIC (бежит к ближайшей лестнице вверх), DROWNING, DEAD. WORK/HAUL/GATHER — заглушки (этап 06).
   - Потребности: декременты по docs/00 §6.3. ⚠️ **Хранить целочисленно, в «милли-единицах» (`satiety_milli: int`, 0..100000), с целочисленным накоплением остатка** — рецепт в [research/11](../research/11-sim-core-determinism.md) §1.3. Наивное `X/3000` за тик даёт бесконечную дробь и накопление ошибки, из-за которого **приёмка save→load на этапе 11 не пройдёт**. Наружу отдавать `satiety() -> float`. Пороги <30 и =0 — с гистерезисом ([research/15](../research/15-agents-fsm-views.md) §4), иначе агент дёргается на границе.
   - Вода: агент в затопленной клетке → wet=true, счётчик тонет: 5 с (50 тиков) → DEAD(cause="drown"); has_gear → 20 с; `drown_seconds` черты. За 2 с до смерти — событие agent_drowning. Вышел из воды — счётчик сброс.
   - Отзыв: `recall(hard)` — все в RETURN; hard: бросить стаки на землю (drop), скорость ×1.15.
   - Тепло: возле источника тепла +30/цикл; мокрый −25/цикл вместо −10. ВНИМАНИЕ: построек ещё нет (этап 07) — сделай заглушку `SimWorld.heat_sources() -> Array[Vector2i]` (радиус тепла — Balance.HEAT_RADIUS=4): на этом этапе список наполняется тестом и клеткой спавна (временный «костёр лагеря», пометь TODO-07); этап 07 заменит его данными очагов.
   - Биография: `bio_key` из const-пула 30 tr-ключей (сидированно), поле агента, показывается в AgentCard (этап 14).
   - События Духа этого этапа: смерть ЛЮБОГО агента → mood −25 у ВСЕХ живых (без проверки дистанции); сырая еда −5; затопление склада (событие storage из этапа 04) → −10 всем; «тёплый ужин»: EAT провизии в радиусе источника тепла → +5.
   - **Пополнение колонии** (docs/00 §6.1): на конце цикла — если средний mood > 60, прошло ≥2 цикла с прошлого пополнения и агентов < 12: шанс 25% (SimRNG) → спавн новичка у точки спавна (имя/черты/биография сидированно), mood +5 всем, запись в отчёт цикла.
4. Команда `Game.cmd_recall(hard)` → sim. События: agent_spawned/updated/died/drowning (updated — при смене состояния/площадки, не чаще 1/с на агента).
