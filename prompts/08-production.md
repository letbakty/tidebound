# Этап 08 — Производство: станции и рецепты

**Модель:** Fable 5 или Sonnet 5 (по готовым таблицам).
**Зависит от:** 07. **Читать:** docs/00 §9.1; docs/02 §5.
**Результат:** все 3 цепочки работают конвейером без ручных заказов.
**Ресерч:** [research/17-buildings-production.md](../research/17-buildings-production.md) §7 — буфер станции, порядок систем, `MaterialRequester`. Дополнительно: [research/14](../research/14-data-resources-tres.md) (генерация рецептов).

## Задача
1. `data/defs/recipe_def.gd` — `class_name RecipeDef extends Resource`: id, station_special: String (у какой постройки), inputs/outputs: Dictionary[String,int], work_seconds: float (0 = пассивный), passive_per: String ("cycle"/"low_phase"/""), needs_agent: bool, unlock_id: String.
2. `data/recipes/*.tres` — все рецепты docs/00 §9.1 дословно, включая сушку плавника на Сушилах и Снаряжение (unlock_id=u_gear).
3. `sim/production_system.gd` — `class_name ProductionSystem`. ⚠️ Порядок систем и **буфер станции** (входы должны физически лежать на станции до старта работы) — [research/17](../research/17-buildings-production.md) §7; подвоз входов — через тот же `MaterialRequester`, что и стройка на этапе 07, иначе задачи задвоятся.
   - Активные станции (needs_agent): станция ACTIVE и не затоплена + входы есть на складах → создаёт STATION-задачу; агент приходит → работа work_seconds (× модификаторы черт: forge_mult/saltery_mult по special) → выход на ближайший склад (или на землю у станции, если складов нет — с предупреждением-событием).
   - Подвоз входов: через JobSystem.request_haul (интерфейс из этапа 06) — материалы должны лежать НА станции до старта работы (буфер станции: Dictionary[String,int]).
   - Пассивные: evaporator — +1 salt в конце LOW, если был не затоплен всю LOW и не шторм (шторма ещё нет: добавь `SimWorld.is_storm: bool = false`, наполнит этап 09); dryer — в конце цикла: 3 kelp → 1 fiber и до 2 мокрых driftwood → сухие; raincatcher/condenser — вода по правилам docs/00 §8.
   - **Лебёдка (winch):** клетка под кромкой = корзина (буфер стаков). JobSystem: HAUL-задача «отнести в корзину» предпочтительнее подъёма по лестнице, если путь до корзины короче; лебёдка поднимает 1 стак / 6 с в ближайший склад наверху (или на землю у себя при отсутствии места) без участия агента; DISABLED при затоплении механизма (сама корзина может быть под водой — предметы в ней вода не уносит).
   - Топливо горна: 1 сухой driftwood на цикл рецепта — часть inputs.
4. События: production_done → в отчёт цикла (счётчики произведённого).

## Приёмка (tests/test_production.gd)
- [ ] Headless-сценарий «полная цепочка соли»: испаритель на −1, солильня, склад с catch и водой → к концу 3-го цикла на складе ≥2 rations.
- [ ] Цепочка металла: утиль+сухой плавник у горна → слитки → верстак → детали.
- [ ] Мокрый плавник горн не принимает; после сушилы — принимает.
- [ ] Испаритель, затопленный на середине LOW, соль в этом цикле не даёт; при is_storm=true — тоже не даёт.
- [ ] Лебёдка: стак из корзины оказывается на верхнем складе через 6 с; агенты с дна предпочитают корзину лестнице при более коротком пути.
- [ ] Кузнец у горна быстрее обычного агента на 25% (замер тиков).
