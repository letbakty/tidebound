# Этап 03 — Дебаг-инструменты (рано, чтобы помогали всем следующим этапам)

**Модель:** Sonnet 5 достаточно (механический этап по чёткой спеке).
**Зависит от:** 01, 02. **Читать:** docs/02 §3 (контракты).
**Результат:** F1-панель с командами и оверлеями; ускоряет отладку всех будущих систем.
**Ресерч:** [research/13-debug-overlays-drawing.md](../research/13-debug-overlays-drawing.md) — сигнатуры `_draw`, троттлинг, гейт релиза, подписка на все сигналы рефлексией, промотка времени. Дополнительно: [research/11](../research/11-sim-core-determinism.md) §10.

## Задача
1. `debug/debug_panel.tscn/gd` — CanvasLayer (layer=100), тумблер F1 (и 4-пальцевый тап — заглушка-хук). Собирается из обычных Control-нод (Panel + VBox), тема не важна.
2. Секции панели:
   - **Время:** пауза/×1/×2/×3 (через `Game.cmd_set_speed`), «+1 фаза» (промотать тики до следующей фазы), «+1 цикл», лейбл: тик/цикл/фаза/уровень воды.
   - **Вода:** слайдер override уровня (-12..+3, чекбокс «override on» — напрямую пишет tide.level_override; добавь это поле в Tide: если не NAN, использовать вместо кривой). ⚠️ **JSON не поддерживает NAN/INF** — они сериализуются как `null`. В `Tide.to_dict()` конвертировать `is_nan(v) ? null : v` и обратно на чтении, иначе сейв ломается ([research/11](../research/11-sim-core-determinism.md) §2, [research/13](../research/13-debug-overlays-drawing.md) §7).
   - **Мир:** чекбоксы оверлеев: граф навигации (линии рёбер + id площадок), отметки ярусов (подписи слева), депозиты (остатки числом), клетки затопления (заливка).
   - **Забег:** «Новый забег (сид…)» с полем сида, «Завершить цикл», лейбл событий (последние 10 SimEvent построчно).
3. Оверлеи — `debug/debug_overlay.gd` (Node2D внутри world, рисует `_draw()` по данным Terrain/Tide; обновление по сигналам, не каждый кадр).
4. Подписка на все сигналы `Events` — **одной строкой через рефлексию** (`get_signal_list()`), рецепт в [research/13](../research/13-debug-overlays-drawing.md) §6: тогда сигналы, добавленные будущими этапами, попадут в лог автоматически. Кольцевой буфер 200 строк — НЕ через print в sim (sim не трогать), а подпиской на Events в панели.

## Приёмка
- [ ] F1 открывает/закрывает; все кнопки работают; оверлеи включаются независимо.
- [ ] Override воды мгновенно двигает WaterView и is_flooded.
- [ ] В релизной сборке панель недоступна (`OS.is_debug_build()` гейт).

## Не делать
Не менять sim-логику (кроме добавления `level_override: float = NAN` в Tide). Не наводить красоту.
