# Звук TIDEBOUND — что нужно и чем заменять

Все файлы в этой папке и в `assets/music/` сейчас **PLACEHOLDER**: синтетика из
`tools/gen_placeholder_sfx.gd`. Они не «звучат хорошо» и не должны — их задача
дать проверить маппинг событий на слух и не блокировать этапы 18–19.

Перегенерировать:

```
godot --headless -s res://tools/gen_placeholder_sfx.gd
godot --headless --import --quit
```

Раскладка шин (`default_bus_layout.tres`) собирается отдельно:
`godot --headless -s res://tools/gen_bus_layout.gd`.

## Правила замены

1. **Имя файла менять нельзя** — id из таблицы ниже зашиты в `autoload/audio_service.gd`
   (константы `SFX_IDS`, `UI_IDS`, `LOOP_IDS`, `MUSIC_IDS`), и тест `test_audio`
   валит прогон, если файла нет.
2. Моно, 16 бит, `.wav`. Лупы — с `loop_mode = Forward` в `.import`.
3. Целевая громкость смеси: **−16 LUFS интегрированно, true peak ≤ −1 dBTP**
   (research/35 §6.1). Отдельные файлы не нормализуем «в потолок»: баланс
   держат шины.
4. Источники — Sonniss GDC Bundle и CC0 (research/35 §1). **CC-BY-NC не брать
   вообще.** Каждый скачанный файл сразу вписывать в `SOURCES.csv` рядом.

## Одноразовые звуки, шина SFX

| id | Что должно звучать | Длит. | Откуда дёргается |
|---|---|---|---|
| `bell` | Колокол Сигнала. Главный звук игры: ~40 срабатываний за забег. Низкая середина 200–500 Гц, быстрый спад, хвост ≤0.9 с — иначе три удара сливаются в кашу (research/35 §3) | 0.6–0.9 с | `phase_changed(SIGNAL)` — три удара с интервалом 0.6 с; `recall_issued` — один |
| `bell_low` | Смерть агента. Низкий одиночный удар, под ним эмбиент проваливается на 2 с | 1.5 с | `agent_died` |
| `splash` | Вода накрыла ярус. Питч-вариация ±6% обязательна | 0.4 с | `water_level_changed`, пересечение целой отметки вверх |
| `phase_shift` | Глухой сдвиг на смене фазы. Не событие, а «поворот» — тише всего остального | 0.5 с | `phase_changed` (любая фаза) |
| `build` | Постройка размещена (план поставлен) | 0.2–0.3 с | `building_placed` |
| `build_done` | Стройка/ремонт завершены, постройка стала ACTIVE | 0.3–0.4 с | `building_state_changed` |
| `break` | Постройку сломало штормом или износом | 0.4–0.6 с | `building_state_changed` |
| `station` | Работа станции: горн, канатная. **TODO:** свой звук на каждый тип станции — для этого в контракт нужно событие производства, сейчас звук общий | 0.4 с | `building_state_changed` у работающей станции, не чаще раза в 1.5 с |
| `work` | Агент работает: кирка, молот. Питч-вариация обязательна | 0.15–0.3 с | `agent_updated`, состояние WORK, не чаще раза в 0.8 с |
| `creature` | Скрежет существа при появлении | 0.8 с | `creature_spawned` (у самого Прихода звука нет — существа звучат поштучно) |
| `thunder` | Гром в начале шторма | 1.5–2 с | `crisis_started(STORM)` |

## Интерфейс, шина UI

| id | Что | Длит. | Откуда |
|---|---|---|---|

## Лупы

| id | Что | Длина | Как управляется |
|---|---|---|---|
| `amb_sea` | Ровный шум моря. **Играет всегда** — общий слой, без которого кроссфейд верх/низ слышен как переключение радио (research/35 §5.1) | 40–60 с | постоянная громкость |
| `amb_top` | Верх утёса: чайки, ветер | 45 с | равномощностный кроссфейд по Y камеры |
| `amb_bottom` | Дно и руины: капель, гул. **Длина не должна совпадать с `amb_top`** — иначе повтор слышен через минуту | 35 с | тот же кроссфейд, встречная громкость |
| `amb_rain` | Дождь шторма, поверх обоих слоёв | 30 с | `crisis_started/ended(STORM)`, фейд 1 с |
| `water_rise` | Шелест поднимающейся воды | 20 с | громкость от скорости изменения уровня |

## Музыка (`assets/music/`)

| id | Что | Длина |
|---|---|---|
| `music_calm` | Отлив и Низкая вода | 2–3 мин луп |
| `music_tense` | Сигнал и Высокая вода | 2–3 мин луп |

Кроссфейд между ними — 2 с, в меню тише на 6 дБ.

⚠️ Музыка — единственная позиция, которую нельзя закрыть бесплатными
библиотеками «хорошо» (research/35 §7). Варианты: заказать, взять
royalty-free, либо осознанно отказаться от музыки и оставить только эмбиент.
Решение за человеком, не за агентом.

## Чего в списке нет и почему

- Позиционное 2D-аудио — не нужно (промпт этапа 17, «Не делать»).
- Отдельная громкость колокола в настройках (research/35 §3.2) — идея хорошая,
  но это новый пункт настроек, то есть обмен на что-то из плана. В `docs/backlog.md`.
- Шаги агентов — шестнадцать пар ног на экране превратятся в шум.
