# Спрайты TIDEBOUND — что нужно художнику

Всё в этой папке сгенерировано программно и помечено **PLACEHOLDER**: силуэт,
два тона, светлая кромка сверху — ровно тот минимум, без которого картинка
читается как «программерский арт». Настоящий арт делается по
[prompts/ART-generation.md](../../../prompts/ART-generation.md) и палитре
`docs/01 §4`; заменяется перерисовкой PNG **без единой правки кода**.

Перегенерировать заглушки:

```
godot --headless -s res://tools/gen_sprites.gd
godot --headless -s res://tools/gen_parallax.gd
godot --headless -s res://tools/gen_ui_atlas.gd
godot --headless -s res://tools/gen_placeholder_tileset.gd
godot --headless --import --quit
godot --headless -s res://tools/gen_theme.gd
```

## Контракты, которые менять нельзя

| Файл | Размер | Контракт | Кто читает |
|---|---|---|---|
| `agent.png` | 96×24 | 6 кадров 16×24 в ряд: 0–3 ходьба, 4–5 работа. Origin — низ-центр кадра | `game/agent_view.gd` (`region_rect`), тест `test_agent_sheet_size` |
| `creature.png` | 32×24 | один кадр, origin низ-центр | `game/creature_view.gd` |
| `placeholder_tiles.png` | 192×32 | 6 тайлов 32×32: утёс, песок, руины, лестница, задняя стенка, кромка. Порядок = индексы в `game/world.gd` | тайлсет `data/tilesets/placeholder.tres` |
| `parallax_far/mist/clouds.png` | 640×N | ширина ровно 640 (= `repeat_size` в `world.tscn`), иначе шов при повторе | `game/world.tscn` |
| `ui_atlas.png` | 80×16 | 5 кадров 16×16: panel, raise, hover, pressed, dark. Поля 9-patch — 5 px | `ui/theme/theme_factory.gd`, тест `test_ui_atlas_matches_theme` |

⚠️ **В атласе интерфейса нет акцентных и «опасных» кнопок намеренно.** Их цвет
зависит от пресета для дальтоников (`UIPalette`), а кадр атласа запечён:
такие стили остаются плоскими, иначе доступность ломается ради текстуры.

## Правила пиксель-арта проекта

- Один пиксель мира = один пиксель текстуры. Мир рендерится в 640×360 и
  масштабируется целыми числами — дробный масштаб спрайта даёт мыло.
- Фильтрация Nearest (задана в проекте), никаких мип-мапов.
- Origin спрайтов персонажей — низ-центр: агент «стоит» на клетке.
- Свет считается в непрерывных координатах: пиксельным его делает
  `assets/shaders/sprite_lit.gdshader` (снап `LIGHT_VERTEX`), а не текстура.
