# Спрайты TIDEBOUND — что нужно художнику

Часть файлов здесь ещё сгенерирована программно и помечена **PLACEHOLDER**:
силуэт, два тона, светлая кромка сверху — тот минимум, без которого картинка
читается как «программерский арт». Настоящий арт приходит из `art-rd/processed`
по [prompts/ART-integration.md](../../../prompts/ART-integration.md) и всегда
заменяет заглушку **перерисовкой PNG, без правки кода** — см. `SOURCES.csv`,
там перечислено, что уже настоящее.

Перегенерировать заглушки:

```
godot --headless -s res://tools/gen_sprites.gd
godot --headless -s res://tools/gen_parallax.gd
godot --headless -s res://tools/gen_ui_atlas.gd
godot --headless --import --quit
godot --headless -s res://tools/gen_theme.gd
```

## Настоящий арт (этап 18)

Идёт из `art-rd/processed/`, **только файлы с суффиксом `_pick`**. Собирается
скриптами, а не руками, — порядок слотов в атласе это контракт с кодом:

```
godot --headless -s res://tools/gen_palette.gd    # art/tidebound.gpl из арта
godot --headless -s res://tools/gen_tiles.gd      # атлас тайлов
godot --headless --import --quit
```

`tools/gen_placeholder_tileset.gd` больше **не** пишет PNG (затёр бы арт) —
только тайлсет; заглушки по старому: `-s ... gen_placeholder_tileset.gd -- stub`.

Что уже стоит на настоящем арте и откуда — `SOURCES.csv` рядом с этим файлом.

Посмотреть арт **в игре**, а не в просмотрщике (единственная годная проверка,
`prompts/ART-integration §3`):

```
tools/shoot.sh out=/tmp/shots zoom=3 ff=400 frames=3 every=30 hud=0 cell=6,4
```

⚠️ `cscale=1.0` заставляет снимать ЧИСТЫЙ ×3. По умолчанию окно масштабируется
ещё и по DPI (`Settings.effective_scale`), и на HiDPI игрок видит мир в ×3.75 —
пиксель тайла разъезжается на 2–3 экранных.

## Контракты, которые менять нельзя

| Файл | Размер | Контракт | Кто читает |
|---|---|---|---|
| `agent.png` | 96×24 | 6 кадров 16×24 в ряд: 0–3 ходьба, 4–5 работа. Origin — низ-центр кадра | `game/agent_view.gd` (`region_rect`), тест `test_agent_sheet_size` |
| `creature.png` | 32×24 | один кадр, origin низ-центр | `game/creature_view.gd` |
| `placeholder_tiles.png` | 192×32 | 6 тайлов 32×32: утёс, песок, руины, лестница, задняя стенка, кромка. Порядок = индексы в `game/world.gd` | тайлсет `data/tilesets/placeholder.tres`, тест `test_tile_atlas_geometry` |
| `parallax_far/mist/clouds.png` | 640×N | ширина ровно 640 (= `repeat_size` в `world.tscn`), иначе шов при повторе | `game/world.tscn` |
| `ui_atlas.png` | 80×16 | 5 кадров 16×16: panel, raise, hover, pressed, dark. Поля 9-patch — 5 px | `ui/theme/theme_factory.gd`, тест `test_ui_atlas_matches_theme` |

⚠️ **В атласе интерфейса нет акцентных и «опасных» кнопок намеренно.** Их цвет
зависит от пресета для дальтоников (`UIPalette`), а кадр атласа запечён:
такие стили остаются плоскими, иначе доступность ломается ради текстуры.

## Правила пиксель-арта проекта

- Один пиксель мира = один пиксель текстуры. Мир рендерится в 640×360 и
  масштабируется целыми числами — дробный масштаб спрайта даёт мыло.
- ⚠️ Ступени зума ×2 и ×4 пиксель-идеальны, **×3 — нет**: внутри вьюпорта это
  зум камеры 1.5, и пиксель тайла становится то 2, то 4 экранных. На шумной
  текстуре камня это терпимо, на прямых линиях (постройки, иконки) — нет.
  Замерено на первом настоящем тайле; аудит просил перепроверить (B5).
- Цвет: только 32 оттенка из `art/tidebound.gpl`. Файл собирается ИЗ арта
  (`tools/gen_palette.gd`), а не наоборот — HEX руками никуда не копировать.
- Фильтрация Nearest (задана в проекте), никаких мип-мапов.
- Origin спрайтов персонажей — низ-центр: агент «стоит» на клетке.
- Свет считается в непрерывных координатах: пиксельным его делает
  `assets/shaders/sprite_lit.gdshader` (снап `LIGHT_VERTEX`), а не текстура.
- ⚠️ В шейдере мира **не трогать** `COLOR` через `texture(TEXTURE, UV)`: на
  входе в `fragment()` `COLOR` уже равен `texture(TEXTURE, UV) * modulate`, и
  повторное умножение возводит цвет в квадрат: так весь слой Ground рисовался
  темнее и кислотнее, и на однотонных заглушках это читалось как «атмосферно»
  (тест `test_shaders_do_not_resample_own_texture`).
