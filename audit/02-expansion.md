## 0. Рамка: боли, в которые должен бить контент

- **Б1.** ~1 действие/мин, LOW пуст 150 с (research/39 §2, 42) → контент должен создавать решения в LOW.
- **Б2.** Конфликт «низко/высоко» механически = один склад (39 §5) → нужны объекты, которые *хотят* стоять низко.
- **Б3.** Мало открытий, нет комбинаций (39 §3.2).
- **Б4.** Мета кончается за 10–16 ч (39 §4, 41 §2.3, 40 §5) → ладдер и коллекции.
- **Б5.** Нет историй «я перехитрил воду» (41 §7).
- **Б6.** Контр-игра Прихода не окупается: 3 визита × 1 поведение (39 §6.4).

**Готовые пустые слоты в коде** (контент = данные, не системы): `CardDef.effects`/`CardKeys` (10 ключей), `TraitDef.modifiers`/`TraitKeys` (20), `Balance.DEPOSIT_KINDS` (новый депозит = строка + слот в CliffDef), `UnlockDef.grants` (5 типов), пулы имён/BIO, событие Итога цикла (сейчас одно — newcomer), `CliffDef` (карта №2 = один .tres), `CaptureMode` (база фото-режима). **Находка:** спека §11.2 ссылается на карту «Полная луна» (`next_spring_add`), которой нет в data/cards — готовый незаполненный слот.

## 1. Дешёвый контент в существующие системы

### 1.1 Карты вылазки (6 → 12–14)

Данные-only (существующие ключи CardKeys):

| Карта | Эффект | Зачем |
|---|---|---|
| «Полная луна» / Full Moon | `next_spring_add +1`, `low_plateau_add −1` | закрывает ссылку спеки §11.2; «заём у моря» |
| «Заём у моря» / Sea's Loan | `low_time_mult 1.4`, `next_spring_add +1` | длинный LOW ценой сизигии (Б5) |
| «Налегке» / Travel Light | `haul_speed_mult 1.6`, `bag_slots_add −2` | профильная вариация fast_haul |
| «Долгий вдох» / Long Breath | `drown_bonus_sec +5`, `gather_speed_mult 0.9` | страховка рейда на −8 |
| «Рывок» / The Dash | `low_time_mult 0.6`, `gather_speed_mult 1.6` | высокий темп — насыщает LOW (Б1) |
| «Глухой колокол» / Muffled Bell | `recall_earlier_sec −15`, `gather_speed_mult 1.2` | осознанный риск ⚠️ проверить кламп отрицательных |

Нужен новый ключ (по полдня): «Дар моря» (`driftwood_mult` ×2 после Высокой), «Ясная ночь» (`visit_count_add` −1 существо), «Крепкий берег» (`no_gnaw`), «Отлив-кормилец» (`refill_mult` ×2).

Риск правил: карты не должны отменять объявленные кризисы «в момент» — только на драфте (как calm_water), иначе трещина в правиле 1.

### 1.2 Черты — не больше, а выразительнее

39 §6.2: 17 из 20 черт — незаметные множители. Вместо расширения — 3–4 черты, меняющие план (взамен слабых):

- **«Береговой» / Shorebound** — не спускается ниже −3 (ключ есть): планирование состава.
- **«Дитя отлива» / Ebb-born** — `no_panic` + `drown_seconds 8`: кандидат на реликвию-гонку.
- **«Тяжёлый шаг» / Heavy Step** — лестницы ×0.7, переноска ×1.3: первый «профильный» агент без приказов.
- **«Сухой» / Dry One** — новый ключ `wet_immune`: не мокнет, яркая история.

### 1.3 Разблокировки Журнала (12 → 17+)

Новые редкие карты (`{"card": ...}` — данные-only, 40–50 очков), «Старт: гарантированный Ныряльщик» (60), «Колокол бьёт на 5 с раньше» (45), «Сушила ×3 плавника» (30), косметика Журнала (15). Главный ответ на Б4 всё равно ладдер (§3.1).

### 1.4 Биографии/имена/эпитафии — данные-only, часы работы

BIO_31–60 («Пересчитывает лестничные перекладины вслух», «Не поворачивается к морю спиной», «Помнит, где стоял город до воды»…), +20 имён (Йорун, Эйдис, Твала, Снорри…). **Причинные эпитафии** — шаблон «Мирра — утонула на −6: до лестницы было 16 тайлов» — самое дешёвое усиление правила 1 (P-2 из 41 §8).

### 1.5 События Итога цикла (1 → 6–8)

Детерминированные, нейтральные/приятные (кризисы-сюрпризы запрещены правилом 1): «Бутылка с запиской» (+5 Духа, строка лора), «Море вернуло» (смытый стак на пляже), «Птицы ушли с утёса» (атмосферный предвестник шторма), «Ясная ночь», «Гость не вышел к костру» (микро-драма без квеста). Закрывает пустые циклы 2/5/8/11.

## 2. Средние фичи

### 2.1 Утёсы №2–3
- **№2 «Расколотый берег»** (M, 1.0): две колонны с седловиной, мало плавника, много соли/обломков — ломает доминирующую стратегию «плавник = бесплатный ключ» (39 §5.1) без новых механик.
- **№3 «Двойная вода»** (L, пост-1.0): два коротких отлива за цикл — весь ритм пересобирается (по модели DLC-биомов Against the Storm).

### 2.2 Новые существа Прихода (без боёвки, тип цели = поведение, объявляются на банере)
- **«Гасильщик» / Snuffer** — гасит ближайший фонарь: свет перестаёт быть абсолютной защитой.
- **«Илоносец» / Silt-bearer** — оставляет ил (работы ×0.5 до расчистки): политика Ремонт оживает.
- **«Сорока» / Magpie** — крадёт строго самый ценный стак: думай, ГДЕ лежит ценное (Б2).
- **«Гнездовик» / Nester** — не отпугнут — занимает узел на следующий LOW.

### 2.3 Погода — только по расписанию на шкале
«Туман» (штраф скорингу дальних целей), «Морось» (дождесборник +2, сушила стоят), «Штиль» (испаритель ×2, плавника 0). Каждая — сдвиг экономики, прогноз обязателен (правило 1).

### 2.4 Постройки: «объекты, которые хотят стоять низко» (ответ на Б2)
- **«Верша» / Tide Weir** (2×1, −3..−1): +2 добычи за Высокую воду, если ЗАТОПЛЕНА — первая постройка, которой затопление полезно.
- **«Волнолом» / Breakwater** (3×1): постройки за ним считают шторм-порог на ярус ниже.
- **«Сигнальная вышка» / Signal Post**: зонный ранний авто-возврат — зонная Осторожность без приказов.
- **Соседства (D-11)**: очаг↔сушила, фонарь↔шлюз, верша↔маяк — первые комбинации (Б3).

### 2.5 Колокол и характер колонии
«Тихий час» (авторитуал после смерти: колония у очага, один удар колокола, +Дух с задержкой), мета-тембры колокола, эпитет колонии по счётчикам забега («Жадная артель», «Сухие», «Кормившие море») — заготовка для достижений.

## 3. Крупные направления

1. **Ладдер сложности / мутаторы — приоритет №1 списка, обязателен к EA при $14.99** (39 §4, 40 §5): 5–7 модификаторов поверх готовых phase_scale/CRISIS_CALENDAR («Быстрая вода», «Скупые руины», «Ранний шторм», «Тёмные ночи», «Голодный берег», «Высокая луна»). Урок Dome Keeper: мутатор = добровольная ставка за множитель очков, а не просто «сложнее».
2. **Daily run по сиду — офлайн** (1.0): сид = f(дата), один заход в день, карточка-итог для скриншота. Без наград/стриков (иначе «никогда»-лист). Steam-лидерборд опционально.
3. **«Долгая вахта» 20 циклов** вместо endless (endless ломает правило 3): после 12-го эскалация по расписанию, судно можно вызвать всегда — «сколько ещё рискнёшь стоять?»
4. **Атлас находок + именные реликвии** (15–20, пул как BIO): коллекция + носитель нарратива; связка с «реликвией-гонкой» P-5.
5. **Фото-режим** (CaptureMode уже есть): рамка с сидом и циклом — каждый скриншот = маркетинг. + «Карточка забега» PNG и «сыграть этот сид» из истории.
6. **Twitch-драфт** — механически идеален (голосование за карту на автопаузе), но спорен против «соцфункции — никогда»: только пост-1.0 после решения владельца.

Отфильтровано: мультиплеер, урон существам (боёвка), процедурные утёсы, записки-квесты, ежедневные награды, магазин.

## 4. Нарратив без диалогов

1. **Именные реликвии** («Судовой колокол без языка», «Ключ от двери, которой больше нет», «Барометр, застывший на „буре“»…) — одна строка в StoragePanel/Атласе.
2. **Журнал смотрителя** — шаблонная хроника забега из уже логируемых SimEvent, в RunSummary и историю.
3. **Обелиски прошлых забегов** — пирамидки в местах смертей из meta.history; тап — имя и эпитафия. Лимит 12 + выключатель.
4. **Звуковые события**: затонувший колокол в руинах на LOW, птицы замолкают за цикл до шторма (прогноз в аудио), дальний гудок судна на 11-м цикле.
5. **Микротексты**: подзаголовок меню (слот пуст в docs/03 §3.3), пустые состояния Журнала («Море пока никого не забрало»), названия сизигий по счёту.
